## Changes in this patch

| Finding | Evidence | Change |
| --- | --- | --- |
| Missing blog H1 | 46 blog index/tag URLs; live `/blogs/blog` had no H1 | One visible primary heading using the existing localized `nbk-page-h1` snippet |
| Invalid product JSON-LD | 167 crawl URLs / 52 unique paths; sampled HTML contained a Liquid `invalid url input` error from an absent variant/product image | Guard absent images before `image_url`; iterate only product images, excluding video media |
| Missing pagination descriptions | 135 of 167 indexable URLs with missing descriptions have a `page` parameter | Render an escaped, localized page-number prefix and the existing description on page 2+; no duplicate first-page description |
| Inconsistent pagination graph identity | HTML canonical retained `?page=2`, while JSON-LD stripped it | Preserve Shopify's canonical URL in structured data |
| Utility-page indexing | Live cart/search explicitly declared `index, follow` | `noindex, follow` for cart, search, 404, legacy customer templates and two standalone size-guide handles; existing collection index rules preserved |
| Broken RU login links | All 100 sampled high-rated pages with internal 4xx linked to `/ru/customer_authentication/redirect` | Normalize Shopify authentication endpoints separately from storefront locale routes; repair initial and dynamic links; escape query separators in both login-link templates |
| Inaccurate shipping/return promises | Every product offer advertised free shipping and free returns, but published store policies have conditions and exclusions | Remove universal offer-level promises and link the Organization return policy to the published `/pages/return` |

A validator also found a pre-existing missing blog section schema translation key. It now uses the existing `sections.all.colors.label` key.

The missing-image fix prevents malformed JSON. It does **not** invent product images or guarantee rich-result eligibility for products without required content. The Ahrefs example `/products/sumka-chokhol-musette-bag-sira` now returns the storefront 404 page, so it cannot be used as proof of a recovered live product. The active carabiner product renders parseable Product and ProductGroup JSON in preview.

Pagination follows [Google's guidance on distinct, self-canonical pagination URLs](https://developers.google.com/search/docs/specialty/ecommerce/pagination-and-incremental-page-loading). The policy link follows [Google's Organization return-policy URL option](https://developers.google.com/search/docs/appearance/structured-data/return-policy). Actual policies checked: [delivery](https://newbornk.com/pages/order-and-delivery), [returns](https://newbornk.com/pages/return).

## Remaining work, in priority order

1. **Re-crawl after release.** The baseline score is unchanged until the new theme code is published and crawled. Confirm RU login links no longer generate 404s, H1 coverage, metadata and JSON-LD. Separate retired product URLs from repaired template defects.
2. **Large images: 18 flagged URLs.** The largest image response in this crawl was 17,512,364 bytes at width 2560, with 335 image references. Review its originating asset and content use, optimize without losing transparency or visual quality, then update the source asset. Do not blindly rewrite all PNGs or replace images based only on a crawler error.
3. **Content metadata.** Of 167 missing indexable descriptions, 135 are pagination and 9 are carts/size guides covered by the new utility noindex rules. The other 23 URL variants need catalog/policy review: coat collection duplicates, Pidnogamy, seasonal sale collections, policy translations and an older product. Confirm which pages remain active and canonical before writing copy or redirecting them.
4. **Retired links and redirects.** Ahrefs reports 86 internal 4xx endpoints, including localized authentication and tracked variants of old product URLs. Recheck after the auth fix. Redirect retired products only to a genuinely equivalent replacement; otherwise remove obsolete internal links and keep a proper 404. Do not redirect every missing product to the homepage.
5. **Further inventory.** Multiple-H1, long/short description and hreflang findings require page-specific review. No bulk truncation, deletion of alternate-language links, or blanket noindex was applied. Hreflang examples included pages not fully crawled; that alone is not proof of a broken translation.
6. **Crawler rate limits.** The broken-image finding involved one image returning HTTP 429, referenced by three pages. Several direct live product requests also returned 429 while browser navigation worked. Recheck after backoff before treating these as missing assets.

The existing nested ItemList on first collection pages was confirmed; no duplicate ItemList was added merely because a top-level-only inspection did not see it. Existing technical noindex/nofollow rules were not removed to improve an audit score.
